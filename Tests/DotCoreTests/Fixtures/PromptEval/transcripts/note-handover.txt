Um, handover note for whoever picks this up. The migration runs at launch before anything reads a path, it's idempotent, and it never deletes from the Keychain, so the old items stay. The one thing that bit me was the log folder, because the log file is opened eagerly, so if you change the order you get a folder that doesn't exist yet. Also the welcome flag is per install and, uh, there's no way to reset it from the UI, only from defaults, which is a gap we should fix at some point.
