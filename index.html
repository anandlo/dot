Engineered Without Compromise

How Dot delivers sub-50ms speed while respecting your privacy.

True Hardware Push-to-Talk

The microphone hardware is physically dormant when the shortcut is not held. Audio capture begins strictly on the physical key-down event and is severed immediately on release.

CGEventTap • Zero wake-word daemons

Sub-50ms Trailing VAD

Traditional tools wait 2–4 seconds after you finish talking to transcribe audio. Dot streams provisional audio in memory and trims trailing silence so words paste the millisecond you let go.

Provisional commit • Instant paste dispatch

Upstream Zero Data Retention

For cloud inference, Dot enforces non-logging headers across providers (mip_opt_out on Deepgram, enable_logging=false on ElevenLabs, storeAudio=false on Azure).

ZDR enforced • No audio training or storage

Keychain Security & Retention

API keys are encrypted in macOS Keychain. Switching between Groq, OpenAI, or Deepgram retains your keys so you never have to re-enter them, with 1-click deletion at any time.

kSecClassGenericPassword • Zero plaintext tokens
