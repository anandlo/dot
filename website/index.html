How it works

Built exclusively in pure Swift 6 and AppKit. Zero Electron overhead, zero background listening daemons, and zero vendor lock-in.

Hardware-dormant audio gating

The microphone is physically unhooked while idle. The audio input stream initializes only when the key is pressed down and terminates immediately upon key release.

Provisional real-time streaming

Audio streams in real-time as you speak so the model processes speech continuously. On release, the trailing silence boundary commits in under 50 milliseconds.

Direct cursor paste

Dot commits your transcript straight into Xcode, VS Code, Slack, Terminal, or any active field via the macOS Accessibility API without touching the clipboard.

Offline or Bring-Your-Own-Key

Run 100% offline using macOS on-device Apple Speech with zero network requests, or plug in your own API keys for Groq, OpenAI, Deepgram, Xiaomi, or self-hosted Ollama.

Controls

A single global shortcut handles recording and instant paste. Fully customizable to any key or modifier combination.

  • ⌃⌥R Hold to dictate, release to commit
  • ⌥⌘V Paste latest transcription
  • esc Cancel active recording
  • ⌘, Open Settings & Providers
  • Double Hands-free latch mode toggle
  • Custom Bind any single key or modifier

Install

Available directly via Homebrew, prebuilt DMG release for Apple Silicon, or compiled straight from source.

Download DMG
Homebrew (Recommended)
$ brew install --cask anandlo/tap/dot
Terminal
$ curl -LO https://github.com/anandlo/dot/releases/latest/download/Dot.zip
$ unzip Dot.zip -d ~/Applications
$ open ~/Applications/Dot.app
Build from source
$ git clone https://github.com/anandlo/dot.git
$ cd dot && ./scripts/build.sh
